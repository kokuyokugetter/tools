# ちょっとしたツール

買い物、料理、仕事や学校で使える日常の計算ツールです。入力はブラウザ内で処理し、ビルドや外部ライブラリは不要です。

| 分野 | ツール |
| --- | --- |
| 買い物 | 単価比較、割引率の逆算、割引後の支払額、税込・税抜の目安 |
| 料理 | レシピの分量を人数に合わせて変更、電子レンジの時間換算 |
| お金・仕事 | 勤務時間・残業時間、割り勘、時給から給料の目安 |
| お出かけ | ガソリン代の目安 |
| 日付・単位 | 日にちの間隔、西暦・和暦と年齢、インチ・センチ変換 |

## ローカルで開く

```sh
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。GitHub Pagesではリポジトリのルートにある `index.html` を配信します。

## ツールを追加する

分野別モジュールに `id`、`name`、`category`、`description`、`keywords` と、`fields`・`calculate(values)` を持つ定義を追加します。単価比較のように入力欄の個数が変わる場合は `mount(form, result, controlFor)` で描画します。ツールの初期値・サンプル・Gitのコミット情報には公開可能な情報だけを使います。
