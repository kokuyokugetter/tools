# ちょっとしたツール

ブラウザで使えるツール集。入力・ファイルの処理は端末内で完結し、ビルドや外部ライブラリは不要です。

| 分野 | ツール |
| --- | --- |
| 買い物 | グラム単価のまとめ比較（最大1,000商品）、実際の割引率の逆算 |
| データ・テキスト | CSVの列別集計と差分比較、JSONの項目一覧、テキストの行差分 |
| 最適化・計画 | 材料の切断計画、金額の組み合わせ照合、工程表とクリティカルパス |
| 統計 | モンテカルロ工程予測、ブートストラップ信頼区間、単回帰と残差CSV |
| ファイル | SHA-256照合、Gzip圧縮・展開 |
| 日付・単位・計算 | 西暦・和暦と年齢、日付差、インチ・センチ、温度、BMI、割合、割引計算 |

買い物の単価比較は「商品名,価格（円）,内容量（g）」を1行ずつ入力すると、100g単価が安い順に表示します。元値と現在価格しか分からないときは「実際の割引率を逆算」で、割引率と値引き額を確認できます。

「計算する」で実行するツールは Web Worker で処理し、実行中に「中止」を選べます。ファイル処理はブラウザの [Compression Streams](https://compression.spec.whatwg.org/) と Web Crypto を使います。SHA-256はHTTPSまたはlocalhostで利用できます。

## ローカルで開く

```sh
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。GitHub Pages では公開ソースのルートにある `index.html` を配信します。

## ツールを追加する

入力と同時に計算するツールは `js/calculators.js` に追加します。実行ボタン付きのツールは分野別モジュールに追加し、新規モジュールなら `js/advanced-tools.js` へ登録します。

ツールはユニークな英小文字・数字・ハイフンの `id`、`name`、`category`、`description`、`keywords`、`fields`、`calculate(values)` を持ちます。検索・カテゴリ・`#id` のリンクに自動で反映されます。Workerで実行する場合の戻り値は `{ text, detail?, artifact? }` です。ダウンロードを付ける場合は `artifact` に `{ filename, text }` または `{ filename, blob }` を指定します。

ツールの初期値・サンプル・Gitのコミット情報には公開可能な情報だけを使います。
